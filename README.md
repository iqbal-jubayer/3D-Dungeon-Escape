<h1>CSE423 Computer Graphics Game</h1>

A 3D game developed as a CSE423 – Computer Graphics Lab project using Python and OpenGL.

<h2>Technologies Used</h2>

1. Python
2. OpenGL
3. PyOpenGL
4. Pygame
5. GLUT

<h2>Installation</h2>

**Clone the repository:**

1. git clone https://github.com/iqbal-jubayer/3D-Dungeon-Escape.git
2. cd 3D-Dungeon-Escape
3. Download and unzip https://drive.google.com/file/d/11XXzTqOpywLN3Ds8XmFBHZ-0T0yor5zF/view?usp=drive_link
4. Place it inside 3D-Dungeon-Escape

**Create a virtual environment:**
1. python3 -m venv venv
2. source venv/bin/activate

**Install the required packages:**
1. pip install -r requirements.txt

<h2>Running the Game</h2>

python3 run.py
